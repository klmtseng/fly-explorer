# 透視果蠅 · Fly Explorer

**神經元是真的,位置是真的。讓它們亮起來的,是照真接線跑出來的模擬。**

線上版:**https://fly-brain-explorer.vercel.app**(手機直式最佳;https://fly-explorer-sage.vercel.app 指向同一份)

把 MaleCNS 雄性果蠅連接組做成 3D 網站,寫給國小到國中生看,但數字的嚴謹度要撐得住專業讀者。
連接組涵蓋整個中樞神經系統(腦 + 腹神經索),共 166,691 顆神經元,
其中 **140,024 顆帶有量測到的三維細胞體座標,網站畫的就是這 140,024 顆**。
在這之上重播一段我們自己跑出來的逃跑反射:有東西撲過來、巨纖維放電、
管跳躍肌與翅膀肌的神經細胞跟著動。

三條路:

- **小朋友版**:一步一步捲的故事,附問答。
- **專業版**:同一條路,給完整數字、每個數字的出處,以及模型的限制。
- **自由探索**:3D 舞台加 34 張說明卡,想開哪張開哪張。

全站中英雙語。網站預設英文,加 `?lang=zh` 進中文。

## 什麼是資料,什麼是我們畫的

畫面上這條線從不模糊,每個畫面的圖例都寫著:

| 畫面上 | 意思 |
|---|---|
| **發光(綠)** | 真實神經元位置,模擬出來的活動 |
| **洋紅** | 我們注入的(模型算不出逼近偵測的輸入),或我們加的(250 ms 之後的收尾) |
| **冷灰線稿** | 果蠅的身體,我們畫的。連接組裡沒有身體 |
| **琥珀** | 運動神經元到肌肉那一段,連接組也沒有;只有時機是真的 |

卡片上每個數字都帶三種標記之一:

- **●** 由本倉的腳本從資料算出來
- **◆** 我們親自讀過的論文(親讀記錄登記在 `docs/verification_log.md`)
- **○** 二手轉引、示意,或未查證

配色規則寫在 `docs/visual_provenance.md`。它存在的理由是:拿到連接組之後最誘人的一件事,
就是做一段看起來活著的動畫,然後讓觀眾自己以為那是量出來的。

## 模型限制(先講清楚)

- 引擎是漏電積分放電模型,參數沿用 Shiu et al. 2024。**只有化學突觸**:沒有電突觸、沒有神經調節、沒有突觸可塑性。
- **這個模型學不會東西。** 權重表載入之後就是唯讀。真果蠅靠 KC→MBON 那 61,210 條連線做嗅覺學習,
  這些連線在資料裡完整存在,在這裡完全不動。
- **視覺前端撐不起訊號。** 刺激視覺柱只讓 LC4 到 1.23 赫茲、LPLC2 到 0,所以「看到逼近」那一步是注入的,
  畫面用洋紅標示並寫明。
- **教科書放在巨纖維與翅膀下壓肌之間的中繼站 PSI,在這個情境裡完全沒放電。**
  把進 PSI 的抑制性輸入歸零重跑,三個種子它都放電,所以壓住它的確實是抑制;
  但解除抑制之後翅膀的讀數完全沒變,而且在真果蠅身上,GF→PSI 是電化學混合突觸,
  電性那一半才是這條迴路的主要型別。連接組只記錄化學突觸,所以
  **這個模型按建構就量不了教科書那條路,它沒放電不能拿來當「教科書不對」的證據。**
  消融數字在 `docs/verification_log.md §PSI 抑制消融`。
- **模型不會自己停。** 跑到 600 ms 的 20 次執行裡,沒有一次自己停下來。
  重播只播到 250 ms,後面的收尾是我們加的,用洋紅標示。
- 複眼六角座標裡「哪個方向是正前方」**尚未驗證**。網站選擇寫明,而不是猜一個。
- **英文翻譯尚未經母語者複審。**

## 跑起來

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/
```

手機直式 308 px 是驗收基準;桌機用 `?preset=low` 走手機路徑。

深連結:`?track=kid|more|free`、`?lang=en|zh`、`?cap=0`(無字幕)、`?card=<id>`、
`?t=<毫秒>`(跳到某一刻)、`?lab=1`(打開實驗台)、
`?lab=<條件>&labplay=1`(直接在舞台上播某個條件,例如 `?lab=rand_311&labplay=1`)。

## 實驗台

`?lab=1` 打開。九種刺激條件,協定與重播完全相同,只換「刺激哪些神經元」。
**每一格都真的各跑 20 次**,頁面顯示中位數與這 20 次的範圍
(`scripts/build_playground.py` → `public/data/playground.json`)。

**這不是瀏覽器裡的即時模擬。** 每一格都是先用完整連接組跑出來的。不做即時是有理由的:
送到瀏覽器的連線檔只有興奮性邊,拿它即時算會一點就爆,而且會推翻本站自己的發現——
PSI 之所以沒放電,正是因為它最強的早期輸入是抑制性的。

其中四種條件另外匯出可播的舞台資料。非基準條件播放時,標準重播的字幕會被換掉、
放電計數器會收起來:那些是為基準那一次寫的,套到別的條件上就是說謊。

每一個中位數與範圍都可以用本倉裡的逐次原始數字重算。但你沒辦法重跑模擬,
因為引擎與帶權重的連線檔在未公開的研究倉裡。

## 閘門(改內容前後都跑)

```bash
python3 scripts/jargon_lint.py          # 小朋友層不得出現術語清單,首次出現要當場解釋(中英)
python3 scripts/audit_numbers.py        # 正文裡每個數字必須在事實欄或 docs/ 找得到(中英)
python3 scripts/audit_claims.py         # 來源路徑必須存在、不得指向未公開的研究倉、不得是空檔
python3 scripts/verify_stages.py        # 字幕裡的毫秒數必須等於出貨情境的實際放電時刻
python3 scripts/retraction_lint.py      # 已撤回的說法不得再出現(content、docs、src、public、dist)
python3 scripts/citation_record_lint.py # 每條 ◆ 都要有登記,且命中那行要帶年份/DOI/PMID
python3 scripts/lang_residue.py         # 英文版 74 個畫面不得殘留中文(6 主畫面 + 34 張卡 × 2 層;需 build + Chrome)
python3 scripts/verify_playground.py    # 實驗台 summary 必須由 runs 重算得出,種子 1 必須等於出貨情境
python3 scripts/disclosure_lint.py      # 專業層承認的限制,讀者層不准悄悄不提
python3 scripts/verify_quotes.py        # 每句「文獻說 X」必須逐字對得上原文(第一次要 --fetch 抓快取)
```

每支都有 `--self-test`,跑的是**指名的那幾個**負向案例,例如「來源指向不存在的檔」
「手改實驗台的中位數」「英文頁殘留中文」。它證明的是**那幾種錯會被擋下**,
不是「錯的東西都擋得住」——這份 README 以前寫的是後者,那是誇大。

2026-09-17 我請一個沒參與建造的模型專門攻擊這些閘門。它做了 25 個明顯錯誤的稻草人,
**當天那八支全部放行。** 那一輪的結構性發現是:閘門守的是 `content/` 與部分 `docs/`,
而 `src/`、`public/`、`dist/` 沒人守,撤回過的說法只要搬進程式碼字串或打包產物就活得下來。
撤回掃描與卡數比對已經擴到那些目錄,英文殘留掃描從 6 個畫面擴到 74 個。
完整清單與還沒補的洞在 `audit/va_20260918.md`。

## 檢查科學,以及評估那個檢查器

上面的閘門回答的是「數字對不對得上、撤回有沒有回流、英文頁有沒有殘留中文」。
它們回答不了**「這句科學上說錯,但用詞乾淨」**。那是另一條線,方法與實測數字在 `docs/sci_eval.md`:

```bash
python3 scripts/sci_claims.py       # 揀出值得查文獻的句子(73 句,不是全站)
python3 scripts/verify_quotes.py    # 「文獻說 X」必須逐字出現在抓回來的原文裡
python3 scripts/disclosure_lint.py  # 承認過的模型限制,不准在送到讀者的路上掉掉
python3 scripts/sci_eval.py         # 盲測一個檢查器:逐類召回、誤報率、兩條基線
```

這個評估不量準確率,因為「這句是不是真的」沒有 ground truth。它量的是**鑑別力**:
拿已驗證為真的句子,注入某一類指定的錯誤但保持用詞乾淨,看檢查器抓不抓得到。
報告**逐類拆開**(任何一類召回 0,整份評估就 FAIL),而且永遠附上兩條基線
(「全部說沒問題」與「全部說有問題」),所以召回率不可能被單獨讀成好消息。

第一次實跑:一個 fresh context、可查網路文獻、只拿到 33 句且不准讀本倉的審查者,
拿到 **16/21 召回、1/13 誤報**;只計算用公開文獻就判得出來的題目是 **10/10、零誤報**。
而只套候選過濾器、完全不做科學判斷的確定性下限是 0.52 / 0.33。

那一輪也推翻了我們自己的兩個判決,以及它自己的一個。兩次更正都寫在 `docs/sci_eval.md` 裡,
因為一次稽核最有用的產出,是那個你必須收回的宣稱。
