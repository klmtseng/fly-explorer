   (那些「輸入變多輸出反而變少」的反轉就是單次抽樣造成的)。已在該檔 docstring 標明。

3. 更根本的問題:**在這些刺激規模下,模型沒有乾淨的「漸進反應」區間**
   ——不是安靜就是引爆,中間地帶不可重現。

### 方法上的更正(重要)

回頭看 Shiu et al. 的作法:他們刺激 21 顆糖受器 1000ms,量的是**特定下游神經元 MN9 的放電率**,
不是全腦總放電。全腦飽和不必然汙染定向讀出。

所以情境盤點的正確設計是:
- 讀出 = **特定運動神經元族群的放電率**,不是全腦總放電
- 必配**同規模隨機刺激對照**(M2 已建立此設計)
- 多 trial,報平均與變異
- 刺激集合用**解剖上有意義的子集**(如逼近物體覆蓋部分視野 → 部分視覺柱),
  而不是整類感覺神經元全開——把 4,107 顆光受器同時以 100Hz 驅動,
  相當於整個視野被閃光燈覆蓋,本來就不是生理情境

其前兩名驅動者正是兩顆 DNp01,+70/+20,3.3ms → 方法可信):

```
翅膀:  LC4 → DNp03(4.9ms) ─┐
       DNp02/04/06/11/103 ──→ AN19B001(6.7ms, 權重 235-419) → DLMn(12.7ms, +802/+672)
       DNp03 ────────────────────────────────────────────→ DLMn(直連 +220/+306)
跳躍:  LC4/LPLC2 → DNp01(3.3ms) → TTMn(13.7ms, +70/+20)
PSI:   28.5ms。最強早期輸入為**抑制性** EA06B010(−185/−132, 11ms),興奮性僅 29-50。
       不是弱,是被壓住。
```

**結論**:模型裡逃跑指令由一整族下行神經元(DNp01/02/03/04/06/11/103)同時廣播,

(且含電突觸,本模型沒有)。與 von Reyn et al. 2017(多 DN 參與逃跑)方向一致,
⚠️ 該文獻本輪未親讀全文,僅摘要層。
