```
rows=211577 annotated=752 distinct=3
putative_ppk23	269
putative_ppk25	257
```

只有三種值,全部帶 putative_(推定)前綴,分別是 ppk23、ppk25、IR52b——都不是糖受器(Gr5a/Gr64 家族)。所以「這隻雄性腦的標註裡沒有糖受器」是**標註欄位的事實**,不是「牠沒有糖受器」的生物學宣稱;要講味覺故事得另找資料,這是卡片 next-new-stories 列為最大未知的原因。

### 門檻取捨(**已套 Traced 過濾,這才是真正會進模擬的規模**)

| 門檻 | 原始邊 | 兩端皆 Traced | 存活率 | 保留突觸 | CSR | 平均出度 |
|---|---|---|---|---|---|---|
| **全部** | 151.9M | **25.6M** | 16.8% | 100% | **146.9 MB** | 155 |
| **≥2** | 57.7M | **15.3M** | 26.5% | **91.7%** | **88.0 MB** | 92 |
| ≥3 | 23.0M | 10.5M | 45.7% | 84.0% | 60.8 MB | 64 |
| ≥5 | 7.6M | 6.2M | 81.8% | 72.3% | 36.3 MB | 38 |
| ≥10 | 2.8M | 2.7M | 98.2% | 54.2% | 16.4 MB | 17 |

🔴 **本檔早期版本的這張表沒有套 Traced 過濾,數字全部高估約 4 倍(說 w≥2 是 330MB,實為 88MB)。**

**為什麼存活率隨權重急升**——弱連結絕大多數牽涉到碎片,不是真神經元:

```
w=1 兩端皆 Traced 10.9%   w=2 13.8%   w=3-4 27.6%   w=5-9 72.1%   w>=10 98.3%
```

碎片(orphan)是重建不完整的神經元片段,被歸給它的突觸自然少 → 邊就弱。
所以**權重門檻有一半的作用其實是在濾掉碎片**;一旦限定 Traced-to-Traced,
門檻的邊際影響就小得多(w≥2 仍保 91.7% 突觸)。

**規模與 FlyWire 相當,這對 M2 是好性質**(兩個連接組規模接近,差異才好歸因):
```
MaleCNS w≥2   165,122 神經元 / 15,270,273 邊 / 出度 92
FlyWire v630  127,400 神經元 / 14,687,178 邊 / 出度 115
```

選定門檻時要寫進 PREREG 並說明理由,不要事後才挑一個好看的。
